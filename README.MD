# ☕ BREW & BEAN — Coffee is an Art

> *A slower kind of wonderful. Beautiful beans, thoughtful hands, and a cup that makes the world wait a little.*

**🔗 Live Website:** [https://krishnamagrawal05.github.io/BREW-BEAN/](https://krishnamagrawal05.github.io/BREW-BEAN/)

---

## 📖 About

**BREW & BEAN** is a concept café website that treats coffee as a daily ritual rather than just a drink. It combines warm, editorial-style design with interactive features, so visitors can explore the menu, build their own cup, pair a drink with food, and collect moments along the way.

> ⚠️ **Note:** This is a front-end concept/demo project. All prices, addresses, phone numbers, emails, opening hours, barista profiles and counters are fictional placeholders. No real orders, bookings or payments are processed.

---

## ✨ Features

### 🍽️ Menu & Ordering
- **Signature drinks**: Brown Butter Cloud Latte, Velvet Cortado, Midnight Cold Brew
- **Filterable menu** with 36 items across Coffee, Cold Drinks, Tea & Matcha, Bakery, Kitchen and Desserts
- **Shopping bag** with live subtotal and a demo checkout flow

### 🧪 Coffee Lab
Build a custom drink by choosing:
- Base (Signature latte, Cold brew, Dark mocha, Cappuccino, Matcha latte)
- Milk (Whole, Oat, Almond, Soy, Coconut)
- Sweetness level, size and an optional extra shot
- The price updates live as you customise

### 🥐 Perfect Pairings
Pick a drink and something from the kitchen, and watch the pairing total update.

### 🛂 Ritual Passport
A collectible coffee passport with 6 stamps. Explore the menu, create a drink or build a pairing to earn stamps. Progress is saved in your browser.

### 🌌 The Experiments
Interactive mini-features that go beyond the menu:
1. **Coffee Universe**: a pointer-reactive cup animation
2. **Latte Art Studio**: Heart, Rosetta and Tulip patterns
3. **Origin Explorer**: discover where beans come from along the coffee belt
4. **Blind Tasting**: guess the mystery tasting note
5. **Design Your Daily Ritual**: personalise a cup card with colour and message
6. **This Week's Pour**: a featured seasonal drink
7. **People Behind the Pour**: barista profiles
8. **Today at Brew & Bean**: sample café counters
9. **Coffee Identity**: pick a mood and get a shareable persona (Slow Starter, Night Owl, Creative Pour)

### 📍 Visit & Reserve
- Café details and directions link
- Reservation request form (demo only)
- Newsletter sign-up

### 🎨 Design
- Responsive layout for desktop and mobile
- Light/dark style toggle (Summer Mood)
- Photo gallery with an enlarged lightbox view
- Smooth scrolling and animated marquee text

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/krishnamagrawal05/BREW-BEAN.git

# Move into the project folder
cd BREW-BEAN

# Open index.html in your browser
# or serve it with a simple local server:
python -m http.server 8000
# then visit http://localhost:8000
```

---

## 🌐 Deployment

The site is deployed with **GitHub Pages**. To deploy your own copy:

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and the `/ (root)` folder
4. Save, and your site will be live at `https://<your-username>.github.io/BREW-BEAN/`
