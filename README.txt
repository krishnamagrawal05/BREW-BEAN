BREW & BEAN — EXTRAORDINARY UPGRADE

FILES
- index.html: self-contained website; embedded CSS and JavaScript included. Open this file or use VS Code Live Server.
- style.css: matching stylesheet copy for editing.
- script.js: matching interactive feature copy for editing.

NEW EXPERIENCES
- Floating coffee universe with pointer response
- Interactive latte art choices
- Coffee origin explorer (Brazil, Ethiopia, Colombia)
- Mystery coffee tasting mini-game
- Custom cup colour and message designer
- Coffee of the week feature
- Fictional barista profile
- Illustrative coffees-served / happy-moments / beans-roasted counters
- Coffee persona card with copy-to-clipboard
- Rotating coffee-ring notes

IMPORTANT
The counters are illustrative demo figures, not real live café data. The barista is fictional. The menu, cart, bookings and rewards are front-end demos; no orders or reservations are sent. External photos/fonts need internet access. For editing, index.html already contains embedded styles/scripts, so make edits consistently or use the external copies as your working source and remove the embedded blocks if you prefer a multi-file setup.
